汇丰 pulse 申请 & schwab 开户

psych
2026-09-01
Life › Finance
Finance, 港卡

本文内容

  1. 港卡申请：包括汇丰 one & 内地神卡汇丰 pulse
  2. 券商开户：受 CRS 影响，加上暂时没有买港股的打算，放弃开港资，选择嘉信国际
🎄非教程向，仅记录。

港卡申请

汇丰 one

  1. 确保港澳通行证有效期大于 6 个月，人肉到 HK
  2. 出境后大约一小时之后可以在移民局 12367 小程序上下载出入境记录 PDF（app 上试过，半天没找到下载的地方，亲测小程序更方便）
  3. 使用一部可以识别 NFC 的手机（iPhone可用），打开 GPS 定位，使用漫游（网上说漫游会断但是我全程漫游申请，没什么大问题）或者连接 WiFi 登陆 HSBC HK，开始申请，具体流程可参考小红书，内地地址填写身份证上的地址，亲测收到 EMS 寄出的短信后可以在 EMS 微信小程序上修改目的地址，需要重新付一次邮费。
  4. 开户成功之后立马注册手机银行，激活的时候可以选择直接给客服发消息也可以打电话激活，主包当时打电话念卡号念了三遍都失败了，最后还是在 APP 上操作的。。
  5. 今年新规定：2026 年申请的卡需要保证近三个月内月均资产不低于 1W HKD，否则需要交每个月 100 HKD 的管理费（并且这个规则是一直存在的，并不只计算开卡后的前三个月），最稳的做法是在激活的当天就转入 1W 等价 HKD（可以存 CNY）

绑定 Apple Pay

9.3 日打开 HSBC 弹窗显示已经不支持红狮子绑定 Apple Pay，已经绑定的没有影响，后悔当时没绑上了，于是赶紧尝试把蓝狮子绑上。刚开始直接在 Apple pay 里面 添加银行卡并填写卡片信息，进入验证环节，跳转 App 会出现错误，直接在 App 打开对应的银行卡下面也没有绑定 Apple Pay 的 Tab，拨打客服选择英语服务一直是人机无法唤起人工客服。。。试了半天最后发现需要先把钱包里的卡片删除，然后直接打开 APP 进入对应银行卡界面就可以看到添加到 Apple pay 的功能，点击后只需要接收验证码就可以顺利绑定。

Timeline

  • 7.25 开卡成功
  • 7.28 蓝狮子实体卡从深圳寄出
  • 7.30 签收

汇丰 Pulse

申请

  1. 26 年 7 月开始放水，持有汇丰 one 账户（无须卓越），并向账户中存入 10W 等价 HKD 的内地用户即可申请汇丰 pulse 信用卡（P.S：7.1 - 7.31 有额外 1000 RC 奖励，但是主包得知这个消息的时候已经八月了，痛失 1000…），不知放水持续多久，截止 8.31 仍刷到下卡记录
  2. 通过跨境支付通搬砖，搬砖主力中国银行（1w/次，5w/天），招商银行（1w/次，1w/天），其余的没试过。尽量不要快进快出，第一天不知轻重一次性转了4.5w中行然后惨遭封禁，两天后解封，转了一笔之后又封了。招商一天一笔，没被封禁过。最好的频率是一个月一个银行一次。
    1. P.S：继中行三天两封跨境支付通之后，不知死活的主包在半个月后快进快出给境外他人账户转了一笔，直接荣获冻结，次日于附近网点耗时十分钟解冻（这一步需要被转人的人脸识别验证身份。。）
  3. 砖到位之后在 HSBC HK 信用卡板块申请 pulse，填写无业方便更快审核
  4. 未做其他操作，几天后顺利下卡

Timeline

  • 8.17 得知消息，开始搬砖
  • 8.20 10 砖到位，填写申请链接，无需补充收入证明材料
  • 8.21 找人工客服确认已进入审核流程
  • 8.25 收到下卡短信
  • 8.28 EMS 寄出，小程序修改地址为现居住地
  • 8.29 收到卡并立刻激活（这一步貌似只需要收到 EMS 寄出短信之后就可以激活实体卡，但为了防止寄丢盗刷还是等卡到了才激活的）

绑定

  • 下载云闪付并绑定（需要没绑定过内地卡，如果之前绑定过则将卡片解绑并注销账户，立即重新注册之后就可以绑定 pulse了）
  • 下载你好中国并绑定，没什么消费场景，但是 26 年有消费券可以薅，貌似是200-50，和100-20，可以买京东京 e 卡的实体卡，美团小象超市卡，还可以支付 12306 的火车订单（需要一定手法从云闪付跳转到你好中国，小红书有教程）。据说一个平台能用一次，且优惠券一般早上八点可以刷新出来，七点五十九分五十几秒开始支付，刚好在八点整跳转到你好中国的方式比较稳。
  • 在钱包中绑定 Apple pay，这一步需要拨打汇丰客服电话告知需要绑定 Apple pay。关于客服电话：把汇丰香港 APP 设计成简易模式-点击联系我们-选择信用卡业务，可以直接获得信用卡业务的客服电话，这样不用二次转接到信用卡服务。亲测耗时四分钟丝滑绑定 Apple pay
  • 微信支付与支付宝绑卡支付最高返点 2.2%，感觉没啥必要。美团直接绑卡有很多盗刷案例，不建议绑
  • 下载 Rewards+ 登陆后报名对应的活动（8000的那个迎新不需要报名；有一个 50RC的迎新（7.1-9.30）不知道是啥，反正我报了；最红自主奖赏，选择赏世界 5X 并登记，会得到 2% 返现；编写快乐假期，中国内地签帐奖赏钱活动，额外 3% 餐饮返现，上限 80/M）

26 年下半年活动

  • 迎新活动，下卡后（注意不是从收到卡开始算）两月内消费满 8000 可以获得 800 RC 返现，这一步应该也包含微信支付和支付宝跳转云闪付的情况
  • 日常消费优选 Apple pay，次选云闪付主扫/被扫，大概率 4.4%返现；通过微信和支付宝跳转到云闪付只有 2.2%
  • 其中餐饮消费每个月满 1200 可以额外获得餐饮部分 3% 返现，上限 80，也就是消费区间在1200 - 2666之间都是3%的额外返现，超过2666就没有了
  • 后续九十月还有 guru 活动，消费够的话还能 叠加 3% - 6%的返现。
  • 有一个特性是美团上面的所有消费都会算做餐饮消费，所以日常美团消费的最低返现是 7.4%

总结一下：

  1. 支付方式首选Apple pay，其次云闪付/你好中国。
  2. 消费渠道首选美图，其次PDD、JD，携程等支持 Apple pay 的软件，避雷阿里系。

券商开户

申请地址：https://international.schwab.com/open-account-intro

教程网上有很多，几乎没什么需要注意的：

  1. 地址证明那里可以下载汇丰 one 的英文版信用卡账单
  2. 地址填写内地地址可以通过，不需要伪造地址
  3. 税务识别号码填写身份证或者港澳通行证应该都可以
  4. W-8BEN 在申请的时候可以先不用填写，但是后面它会发邮件过来让补充表单

申请成功标志：收到黑妹邮件：Your tomorrow starts today.

然后可以下载 schwab app，亲测开了梯子会更丝滑，不开也行。登陆的时候需要接受验证码，这一步国内手机好像就收不到了，需要给schwab打电话，这里可以选择直接打国区电话用中文服务：4001206217，需要提供自己的八位账号，在网页版中依次点击：账户 - 账户一览 - Individual - 更多 - Account Number。

登陆成功之后避免后续每次都需要电话验证，可以通过 VIP access 用 Credential Code 登陆：

  1. 登录 Charles Schwab 网页主页右上角点击 Profile > Security Settings
  2. 进入Security Settings 页面选择 2-Step Verification，接着选择 Always at login > Security token > Continue
  3. 输入 Security token，这一步需要在手机上安装 VIP Access。安装之后打开 app 可以看到Credential ID 和 Security Code
  4. 设置完毕后，再次登录 Charles Schwab 网页或者手机 app 输入完密码之后，页面会跳转到Security Code 验证页面

入金

看教程说可以直接走汇丰转到嘉信在香港的花旗银行账户。全程只有 HKD 到 USD 的汇损。
